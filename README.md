# 🔐 PDF Password Cracking & Security Lab

## 📌 About the Project

This repository documents my hands-on cybersecurity experiments involving PDF password recovery and hash-based password-cracking techniques.

The exercises were performed using sample PDF files provided by my instructor for educational purposes.

The objective was to explore different password-recovery tools, understand hash-based attacks, and gain practical exposure to cybersecurity concepts.

## 🛠️ Tools & Technologies Used

- **Johnny (John the Ripper GUI)** – PDF hash-based password recovery.
- **NetworkWalks Hash Calculator** – Hash calculation.
- **NetworkWalks Password Cracker** – Password recovery.

## 🧪 Practical Experiments

### Experiment 1: Password Recovery Using Johnny

**Tool:** Johnny – John the Ripper

Steps performed:

1. Extracted the password hash from the sample PDF.
2. Saved the extracted hash in a text file.
3. Imported the hash file into Johnny.
4. Started the password-recovery attack.
5. Successfully recovered the PDF password.

**Result:** Password recovered successfully.

### Experiment 2: Password Recovery Using NetworkWalks

**Tools:** NetworkWalks Hash Calculator and Password Cracker

Steps performed:

1. Explored hash calculation using the NetworkWalks Hash Calculator.
2. Used the NetworkWalks Password Cracker.
3. Initiated the password-recovery process.
4. Successfully recovered the password of the second sample PDF.
5. Captured the successful lab flag.

**Result:** Password recovery completed successfully.
